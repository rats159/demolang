# Demolang
A small, intentionally minimal language designed as a base for a (hopefully soon to come) series of videos about various extensions you can make to a programming language. The codebase is meant to have a similar feel to crafting interpreters, but with a bit more meat to it, including both an AST and a bytecode VM

## Planned Extensions
- Arrays
- Static typing
- Value types
- Unions
- Reflection
- Linting
- Pointers
- Imports / Packages
- Closures
